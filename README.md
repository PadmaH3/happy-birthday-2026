# Happy Birthday 2026

An interactive illustrated birthday page: two shuttered windows on a sunlit wall, opened by clicking, ending in a typed note.

## Site

Open any of these directly in a browser (self-contained, no build step):

- `site/two-windows.html` — cinematic version (21:9 crop on desktop, full scene on mobile)
- `site/two-windows-full-scene.html` — always shows the full uncropped illustration
- `site/prompt-pack.html` — the image/video generation prompts used to produce the artwork states

## Assets

- `Plates/` — the five illustration states (both closed, left open, right open, both open, blush) used by the site
- `wide/` — wide-panorama experiments for the cinematic 21:9 treatment
- `dump/` — miscellaneous generation attempts and intermediate images
- the four `artlotus_extend_image_on_both_sides_to_get_219_aspect_ratio...png` files — outpainting attempts at the project root
